## 📖 About

🔹 **Terraria — Boss Cursor** is a powerful tool built to help you always know where bosses are during Terraria fights with a directional boss cursor indicator. An arrow cursor shows the direction to any active boss, keeping you oriented during frantic off-screen combat.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Boss Cursor** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Terraria modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Boss Arrow | Directional arrow indicator pointing toward off-screen active bosses |
| All Bosses | Works for all vanilla and modded boss entities simultaneously |
| Distance Display | Optional distance counter showing how far away the boss currently is |
| Customizable | Adjust arrow size, color, and display conditions in mod settings |
